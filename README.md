# Interactive HTML BOM plugin for KiCad
## Supports EasyEDA, Eagle, Fusion360 and Allegro PCB designer

![icon](https://i.imgur.com/js4kDOn.png)

This plugin generates a convenient Bill of Materials (BOM) listing with the
ability to visually correlate and easily search for components and their placements
on the PCB. It is particularly useful when hand-soldering a prototype, as it allows
users to quickly find locations of components groups on the board. It is also possible
to reverse lookup the component group by clicking on a footprint on the board drawing.

The plugin utilizes Pcbnew python API to read PCB data and render silkscreen, fab layer,
footprint pads, text, and drawings. BOM table fields and grouping is fully configurable,
additional columns, such as a manufacturer ID, can be added in Schematic editor and
imported either through the netlist file, XML file generated by Eeschema's internal
BOM tool, or from board file itself.

There is an option to include tracks/zones data as well as netlist information allowing
dynamic highlight of nets on the board.

For full description of functionality see [wiki](https://github.com/openscopeproject/InteractiveHtmlBom/wiki).

Generated html page is fully self contained, doesn't need internet connection to work
and can be packaged with documentation of your project or hosted anywhere on the web.

[A demo is worth a thousand words.](https://openscopeproject.org/InteractiveHtmlBomDemo/)

# InteractiveHtmlBom for KiCad 11 Nightly

> **Unofficial compatibility fork.** This repository is not an official
> OpenScope or KiCad release. It keeps the familiar InteractiveHtmlBom user
> interface while adding support for KiCad 11 development builds (shown as
> 10.99 nightlies).

This fork is based on InteractiveHtmlBom 2.12.0 and the IPC API work from
[upstream pull request #555](https://github.com/openscopeproject/InteractiveHtmlBom/pull/555).
It adds a targeted compatibility fix for the `ReferencePoint` objects emitted
by newer KiCad 10.99 builds, plus persistent error reporting for plugin startup
failures.

## Status

- Tested on Windows with KiCad Nightly 10.99.0.
- The normal iBOM settings dialog and toolbar action are retained.
- Tested with a real 141-footprint board; HTML generation completed and opened
  successfully in a browser.
- The legacy SWIG path remains available for older KiCad installations.

See [NIGHTLY_PATCH.md](NIGHTLY_PATCH.md) for technical details, limitations,
test results, and troubleshooting information.

## Installation for KiCad 10.99 / 11

1. Download the repository ZIP or a release archive.
2. Extract it into the user plugin directory so that `plugin.json` is directly
   inside the extracted folder:
   `Documents/KiCad/10.99/plugins/<folder-name>/plugin.json`.
3. In KiCad, enable the API server under **Preferences → Plugins**.
4. Restart the PCB Editor.
5. Use **Generate Interactive HTML BOM** from the toolbar or external plugins
   menu.

KiCad creates a per-plugin Python environment and installs the dependencies
listed in `requirements.txt`. On Windows, wxPython is normally inherited from
the Python installation configured in KiCad.
